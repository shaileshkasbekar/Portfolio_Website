Featured Systems · Database Engine

MiniDBMS: Relational Database Engine in C++17

A relational database engine built from scratch, without MySQL or SQLite. It includes an SQL lexer and recursive-descent parser, a query executor, a rule-based query planner with EXPLAIN, and persistent 4 KB page storage with an LRU buffer cache.

  • Disk-based B+ tree indexes with node splits, borrow/merge, range scans and page reuse. Indexed lookups ran about 2,000× faster than full table scans on 100,000 rows (tree height 3).
  • Multiple databases (CREATE/USE/DROP DATABASE), INSERT/SELECT/UPDATE/DELETE, and persistence across restarts
  • PRIMARY KEY, UNIQUE and NOT NULL constraints, and aggregate functions
  • MiniDB Studio: a browser SQL dashboard on a C++ HTTP/JSON API, secured with session tokens, Host/Origin checks and CSP
  • Verified by 58 unit/integration tests and a headless-Chrome end-to-end test suite
